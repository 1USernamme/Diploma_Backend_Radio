# 📡 SDR Signal Analytics Backend (Django REST Framework)

Бекенд-частина системи моніторингу ефіру та виявлення радіоелектронних загроз. Забезпечує цифрову обробку сигналів (DSP) за допомогою швидкого перетворення Фур'є (FFT), розрахунок відношення сигнал/шум (SNR) та авторизацію користувачів за допомогою JWT.

---

## 🛠️ Технологічний стек
* **Фреймворк:** Django REST Framework (DRF)
* **Автентифікація:** JWT (`rest_framework_simplejwt`)
* **Обробка сигналів та математика:** NumPy, SciPy (модуль `fft`)

---

## 🔬 Математика та Наукова Логіка
Система аналізує отримані часові відліки амплітуди та переводить їх у частотну область за допомогою **FFT (Fast Fourier Transform)**.

1. **Розрахунок SNR (Signal-to-Noise Ratio):**
   Обчислюється відношення максимальної амплітуди піку до середнього значення амплітуд усього спектру (шумової полиці):
   $$SNR_{dB} = 20 \cdot \log_{10}\left(\frac{A_{max}}{A_{average}}\right)$$
2. **Критерій виявлення загрози:**
   Сигнал вважається аномалією (загрозою), якщо максимальний амплітудний пік перевищує середній рівень шуму **більше ніж у 3.5 рази**, а знайдена частота строго більша за 0 Гц.
